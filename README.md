# Speed Camera offline maps

Regional OpenStreetMap packages for the personal Speed Camera Android app.

The app reads [`catalog.json`](catalog.json), displays exact download and installed
sizes, verifies SHA-256 checksums, and installs one selected package on the phone.

## Dominican Republic

- **Map only:** nearby street geometry for the recorded minimap.
- **Full offline:** map geometry, address/place search, and driving/rerouting graph.

Source data: [Geofabrik Haiti and Dominican Republic extract](https://download.geofabrik.de/central-america/haiti-and-domrep.html).
Data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright),
available under the [Open Database License](https://opendatacommons.org/licenses/odbl/).

Generated packages belong in the `maps-2026-08-11` GitHub Release and must not be
committed to the Git repository.
